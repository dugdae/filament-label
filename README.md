# Filament Labels

Small web page for printing 40×30 mm labels on a NIIMBOT B1 PRO over Bluetooth:

- **Filament** tab: title, colour, cost, purchase date
- **Model (Serie Z)** tab: big bold code `Zxx.Rxx.Pxxx.xx`, date (default today) and a box for handwriting (optional typed Note fills the box)

Open in Chrome on Android: https://dugdae.github.io/filament-label/

Uses [niimbluelib](https://github.com/MultiMote/niimbluelib) for the printer protocol.
